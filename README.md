# JBurdik/homebrew-tap

```sh
brew tap jburdik/tap
brew trust jburdik/tap          # newer Homebrew asks you to trust third-party taps once
brew install --cask jburdik/tap/crazy-delivery
```

Crazy Delivery – arcade delivery game with a mystery twist (macOS, Apple Silicon + Intel, signed + notarized).
Also playable in the browser: https://delivery.burdych.net/ · direct download: https://delivery.burdych.net/download
